# دليل هوية بن زومة المتحركة

تم تنفيذ طبقة تصميم جديدة مستوحاة من فيديو الهوية المرفق، مع الحفاظ الكامل على البيانات ومسارات العمل الخلفية. تستخدم الواجهة درجات الكحلي والنيلي والفضي مع إبراز ذهبي، وتضيف حركة قصيرة وهادئة بدل المؤثرات المستمرة المشتتة.

## ترتيب التنقل

| الأولوية | المجموعة | المحتوى |
|---|---|---|
| 01 | التحكم الرئيسي | الرئيسية، لوحة المدير، لوحة الأسطول، دورة التشغيل، مؤشرات الأداء، التحليلات |
| 02 | فهم النظام | من نحن، كيف يعمل النظام، الأسئلة الشائعة |
| 03 | التشغيل اليومي | الجدول الأسبوعي، النقل، تطبيق النقل، الساحات، التتبع، التسليم والاستلام |
| تشغيلي | الأفراد والمركبات | الموظفون، المركبات، السائقون، الربط، جودة البيانات، التنبيهات، الوثائق |
| تشغيلي | الصيانة والمخزون | الورشة، المحروقات، الزيوت، الإطارات، البطاريات، قطع الغيار، الغسيل |
| ثانوي | المالية والنظام | المشتريات، العهد، الفواتير، السجلات، التدقيق، الإعدادات والخروج |

## الحركة والهوية

تظهر شاشة الهوية مرة واحدة في الجلسة على صفحة الدخول، ويمكن تجاوزها فورًا. تستخدم الشاشة ملف WebP متحركًا حقيقيًا بخلفية شفافة، مع صورة PNG شفافة كبديل. بعد ذلك تظهر بطاقة الدخول ضمن طبقة زجاجية داكنة، مع شعار ثنائي اللغة وحركة طفو خفيفة وزر ذهبي واضح.

تتضمن صفحات النظام حركة دخول قصيرة للمحتوى، وحركة بسيطة لشعار القائمة، وانتقالات للأزرار والبطاقات. تتوقف الحركات تلقائيًا للمستخدم الذي يفعّل `prefers-reduced-motion`.

## تجربة الجوال

يعتمد التصميم على تدفق رأسي قابل للتمرير بدل قص المحتوى، مع أهداف لمس مريحة، وتقليل تفاصيل الترويسة في المساحات الصغيرة، وتحويل صفحات المعلومات إلى عمود واحد. كما توجد معالجة خاصة للشاشات القصيرة لتقليل ارتفاع بطاقة تسجيل الدخول وإبقاء زر الدخول ظاهرًا.

## الأصول

- `static/binzomah_brand_intro.webp`: شعار متحرك شفاف، 48 إطارًا، 640×266.
- `static/binzomah_brand_transparent.png`: شعار ثابت شفاف عالي الدقة، 1000×356.
- `static/css/brand_motion.css`: الثيم والحركة والاستجابة للجوال.
- `static/js/brand_motion.js`: شاشة الترحيب، التخطي، واحترام تفضيلات الحركة.

## الخصوصية والبيانات

لم يتم تعديل أي نموذج بيانات أو سجل تشغيلي. التغييرات محصورة في العرض، التنقل، صفحات الإرشاد، وأحداث قياس UX التي لا تحفظ الاسم أو البريد أو عنوان IP.
