# نظام تنبيهات صلاحية الوثائق

تم تجهيز مكوّن قراءة فقط للتنبيهات في `services/document_alerts.py`. يلتقط المكوّن الوثائق المنتهية والوثائق التي ستنتهي خلال 30 يومًا، ويبني رسالة موحّدة تتضمن **اسم السائق ورقم المركبة ونوع الوثيقة وتاريخ الانتهاء**.

## الوضع الحالي

الإرسال معطّل افتراضيًا. لا توجد عناوين مستلمين أو أرقام واتساب داخل المستودع، ولا تُقرأ قيم الأسرار من الشيفرة. المكوّن يعرض حالة آمنة فقط ولا يعيد التوكنات أو بيانات الاعتماد.

## متغيرات البيئة المطلوبة عند التفعيل

| المتغير | القيمة الافتراضية | الغرض |
|---|---:|---|
| `DOCUMENT_ALERTS_ENABLED` | `0` | مفتاح تشغيل عام، ويبقى `0` حتى الاعتماد النهائي |
| `DOCUMENT_ALERT_WINDOW_DAYS` | `30` | نطاق التنبيه قبل الانتهاء |
| `DOCUMENT_ALERT_EMAIL_ENABLED` | `0` | تفعيل قناة البريد بعد إعداد المزود |
| `DOCUMENT_ALERT_WHATSAPP_ENABLED` | `0` | تفعيل قناة واتساب الرسمية بعد إعداد المزود |

تُحفظ بيانات اعتماد البريد وواتساب والمستلمون في **Environment Variables** بمنصة الاستضافة فقط، وليس في GitHub أو ملفات المشروع. يجب استخدام مزود واتساب رسمي مع قالب رسالة معتمد، وعدم استخدام أتمتة WhatsApp Web غير الرسمية.

## تسلسل التفعيل المقترح

1. إضافة المستلمين المعتمدين إلى إعدادات الاستضافة.
2. إضافة أسرار مزود البريد ومزود WhatsApp Business أو Twilio إلى إعدادات الاستضافة.
3. اختبار وضع المعاينة الذي يبني الرسالة دون إرسال.
4. تفعيل البريد وحده ومراقبة أول رسالة.
5. تفعيل واتساب بعد اعتماد القالب والرقم.
6. تفعيل `DOCUMENT_ALERTS_ENABLED=1` بعد التحقق من السجلات ومعدل التكرار.

لا يغيّر هذا المكوّن بيانات الموظفين أو المركبات، ولا ينفّذ إرسالًا في وضعه الحالي.
